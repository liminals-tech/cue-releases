# Cue releases

Downloads for **[Cue](https://cue.liminals.tech)**: live screen annotation for Windows, by [Liminals.tech](https://liminals.tech).

- **Install:** open the [latest release](https://github.com/liminals-tech/cue-releases/releases/latest), download `Cue_*_x64-setup.exe` and run it. It installs for your user only, so no admin rights are needed.
- **Update:** Cue checks this page for new versions and offers them from its tray menu. You can turn the check off in Settings → General.

This repository holds only the installers and the update feed (`latest.json`). Every package is signed, and Cue installs only packages signed with the Cue release key.

Cue is built on [Penlight](https://github.com/Ramonvdo/penlight) (MIT License).
